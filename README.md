# A Sala dos Buscadores — Landing page

Landing pública da plataforma, codada a partir da versão "v3 Galeria" do Figma.

## Rodar

```bash
npm install
npm run imagens   # baixa as imagens do site; lista as que faltam exportar do Figma
npm run dev       # http://localhost:3000
```

## Abrir no VS Code com Claude Code

```bash
code .
claude
```

O `CLAUDE.md` explica a estrutura, os tokens da marca e as pendências para o Claude Code.
